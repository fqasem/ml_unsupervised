# Unsupervised Learning Projects

This repository contains Jupyter notebooks and utility scripts for the Unsupervised Learning portion of the Stanford Online Machine Learning Specialization.

## Included materials

- K-means and clustering exercises
- Anomaly detection notebooks
- PCA and visualization examples
- Collaborative filtering and recommender system assignments
- Supporting Python utilities and test files

## Environment

It is intended to be used with Python and Jupyter notebooks. Install dependencies with:

```bash
pip install -r requirements.txt
```

## Project structure

- `*.ipynb` — notebook exercises and assignments
- `data/` — datasets used by the notebooks
- `images/` — generated images and visual outputs
- `*.py` — utility functions and helper modules
- `requirements.txt` — Python package requirements

## Notes

This project is for learning and coursework purposes, and may include course-provided starter code and data.
